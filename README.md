# Procedural-Life

A game where you play as a snake stranded in the desert and have to eat to survive and grow longer every bite! The game is inspired by the desertic atmosphere of the Sahara Desert and uses procedural animation with shaders to deliver a vibe of beeing in an endless sand sea of strand.
